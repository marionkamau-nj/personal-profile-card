# Personal Profile Card

## Project Description
A beginner-friendly personal profile card built using HTML and CSS, with basic JavaScript functionality.

## Features
- Personal profile information
- Profile image
- Skills displayed as badges using Flexbox
- Responsive card layout
- Button hover effects and smooth transitions
- Interactive button that displays a welcome message

## Technologies Used
- HTML5
- CSS3
- Flexbox
- JavaScript

## What I Learned
- Creating layouts using CSS Flexbox
- Styling profile images and skill badges
- Using CSS hover effects and transitions
- Making layouts responsive
- Adding basic interactivity with JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
